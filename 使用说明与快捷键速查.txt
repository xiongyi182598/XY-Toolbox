           XY工具箱 · 施工图深化提资全套自动化工具集
               (纯绿色 · 独立解耦 · 随拷随用版)
============================================================

【特点与优势】
1. 真正解压即用：无需安装 Python，无需管理员权限，支持任意电脑、U盘随拷随用！
2. 绿色零冲突：采用 Autodesk 官方标准 ApplicationPlugins 架构，绝不篡改注册表启动组、绝不感染原有 acaddoc.lsp、与天正建筑/海龙工具箱 100% 完美共存！
3. 毫秒级性能：核心功能由高性能 C# .NET 原生构建，零黑屏、无卡顿。
4. 全模块高解耦：穿透冻结、属性文字平移、极速合并、归0层随层、输入法智能切换均互相独立。

【在任意电脑的使用步骤】
1. 把整个文件夹复制到电脑的任意位置 (如 D盘、E盘、桌面均可)。
2. 双击运行【一键安装】双击即可永久使用.bat 即可一键挂接。
3. 打开 AutoCAD 或 天正建筑，工具箱全自动就绪！

【核心高频快捷键速查】
- 侧边工作台显隐 : XGJ (或 XYPANEL)
- 穿透冻结图层   : XDJ (支持穿透嵌套块与视口局部冻结，支持 U 键微步撤销)
- 零黑屏逐步解冻 : XJD (回车逐步撤销解冻，杜绝重生成黑屏)
- 一键恢复图层   : XHF (瞬间恢复本轮被冻结的所有图层)
- 属性块文字平移 : XSY (或 MW / MY，单字自由平移，同名块联动)
- 图层极速合并   : XJH (或 HB1，免弹窗，点选两下 0.005 秒瞬间完成)
- 图层规范化面板 : XHB (或 HB2，支持前缀规范清洗与视口属性继承)
- 图块一键归0层  : XGL (或 B0，穿透深层嵌套块，图元归0层随层)
- 免炸开穿透删除 : KSC (或 XSC / BDE，免炸开穿透框选/点选删除，支持 M 键切换联动/独占)
- 底层图元探测   : XTC (穿透复杂嵌套块，探测文字与图元属性)
- 输入法智能切换 : XSRF / IME (绘图与命令保持英文盲打，编辑文字自动切中文)
- 图块镜像文字翻正 : FZW (或 XFZ，穿透图块翻正所有镜像反字，自动保位、支持多次镜像手性自适应)
- 免在位编块拉伸 : XKB (或 KBLS，穿透拉伸S/平移M，无需进入块编辑器)
- 在线检测升级   : XGX (或 UPDATE，支持 GitHub 与多线路智能镜像加速升级)
- 快捷键自定义   : XKJ (或 SETKEY，可视化修改快捷键，即刻热重载)
- 程序热重载     : XCZ (无需重启 CAD，秒级热重载最新代码)


【分发到其他电脑或商业交付建议】
1. 如果在开发机进行了修改，可先双击运行【一键商业打包发布】生成纯净更新包.bat，将程序精简合并为标准正式版。
2. 将本文件夹压缩为 zip 或直接拷贝到目标电脑任意盘符（路径中尽量避免特殊符号）。
3. 在目标电脑上双击【一键安装】双击即可永久使用.bat 即可，无需管理员权限，兼容各版 AutoCAD/天正。

【卸载方法】
双击运行【一键卸载】彻底清理还原.bat 即可秒级还原，零残留！
